Selected work

Products we architected, built and deployed. Most are live and linked, so you can click through and use them.

  • Bellefie AI

    AI-powered conversational commerce and price negotiation

    A multi-agent negotiation engine that lets Shopify shoppers haggle in real time and get bundle recommendations. We built the merchant portal, embeddable chat widget and Shopify app, and run it on AWS ECS Fargate.

    Python, FastAPI, React, NestJS, MySQL, Remix, Shopify APIs, OpenAI, LangChain, Redis, Socket.IO, Stripe, AWS Cognito, ECS Fargate, App Runner, Amplify, Docker, GitHub Actions

  • Allset

    Event planning and group payments platform

    Hosts create events with supplier packages, invite guests by email, SMS or contact import, track RSVPs and collect money through Stripe Checkout with automatic fee splitting. Includes OTP login, real-time notifications and an admin panel.

    React, Vite, NestJS, Prisma, Postgres, Stripe, Socket.io, Better Auth, AWS ECS, ECR, S3, SES, SNS, React Query, Tailwind, Docker, GitHub Actions

  • Fitcoin

    Blockchain-based fitness rewards app

    Rewards calorie burn with crypto on Ethereum. We delivered the dashboard and statistics, WalletConnect and RevenueCat integration, social logins, and Fitbit and Garmin activity sync, leading a team of three.

    React, Golang, MySQL, Cypress, WalletConnect, RevenueCat, Redux, Tailwind

  • Cell Operative

    Digital workplace supervisor for retail stores

    Recurring task scheduling by department, live store statistics and daily completion tracking for grocery retailers in Sweden. Led a team of four and handled TestFlight releases.

    Next.js, NestJS, Redux, Tailwind, React Chart, App Store Connect

  • NDC Pharmacy

    Pharmacy insurance and profit analytics

    Multi-pharmacy management with pricing groups, automated CSV imports from pharmacy systems, and dashboards that compare filled prescriptions against recommended NDC selections to reduce claim rejections.

    React, NestJS, Postgres

  • Kitcod

    In-app social community for consumer apps, Antler-funded

    A drop-in community layer with groups, posts and stories that consumer apps embed to keep users engaged. Built in Flutter with AWS Lambda functions behind it.

    Flutter, AWS Lambda

  • Workleague

    Gamified sales performance app

    Turns sales teams into football leagues: calls, meetings and deals feed a live league table on web and mobile, with data kept in sync between both.

    Angular, Flutter, Firebase

  • Kinfolk HQ

    Employee onboarding experience platform, Antler-funded

    Onboarding flows for HR and People teams, a point-based recommendation engine in Node.js, and Lambda functions that match employees and notify them in Slack. Backend on AWS Amplify with DynamoDB, Identity and S3.

    React, Node, AWS AppSync, DynamoDB, GraphQL, Redux, Tailwind

How a project runs

            

              The same shape whether it is a two-week Fiverr order or a
              year-long product build.
            

          


          
    
            
  1. 
              
    Brief
    
              
    
                A call or a written brief. We ask about users, deadlines and what
                already exists, then send back scope, timeline and price in
                writing.
              
    
            
    2. 
            
  2. 
              
    Plan
    
              
    
                Architecture, data model and screen list agreed before code.
                For larger builds this is a short paid discovery so nobody
                guesses.
              
    
            
    3. 
            
  3. 
              
    Build
    
              
    
                Weekly demos on a staging URL. You see progress in the product,
                not in a status report, and can change direction early.
              
    
            
    4. 
            
  4. 
              
    Ship
    
              
    
                Production deployment on your own cloud accounts and app store
                listings, with CI/CD so future releases are a merge, not a
                ceremony.
              
    
            
    5. 
            
  5. 
              
    Support
    
              
    
                Handover docs, a recorded walkthrough, and a retainer option if
                you want the same team to keep building.
